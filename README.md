# 🧢 Pokedex App

A Pokédex application built with React that allows users to explore Pokémon information through a dynamic and interactive interface.

The project focuses on component-based development, API consumption, global state management and navigation between application views.

## 🚀 Features

- Explore Pokémon information.
- Consume data from an external Pokémon API.
- Dynamic and reusable React components.
- Navigation between different application views.
- Global state management with Redux Toolkit.
- HTTP requests with Axios.
- Responsive user interface.

## 🛠️ Technologies

- React
- JavaScript
- Redux Toolkit
- React Redux
- React Router DOM
- Axios
- Vite
- CSS

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sandovaleloy/Pokedex-App.git
```

Navigate to the project:

```bash
cd Pokedex-App
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local address provided by Vite.
